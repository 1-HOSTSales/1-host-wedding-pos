# 1-HOST Wedding Order POS

A single-file, self-contained HTML point-of-sale tool for 1-HOST wedding order taking.

## Features
- Couple name, venue, and wedding date entry
- Wines, D.I.Y Cocktail Bar, Live Stations, and Canapés catalogues
- Automatic complimentary-bottle calculation for wines (12/18/24/30 bottle tiers)
- Automatic complimentary-set calculation for canapés (every 3 sets = 1 free, every 5 sets = 2 free)
- Auto-tabulated Subtotal → Service Charge (10%) → GST (9%, compounded) → Grand Total
- Save orders and reprint/bill from saved order history
- Print-ready invoice with 1-HOST branding

## Usage
Open `1-HOST-Wedding-Order-POS.html` directly in a browser. No build step or server required.
